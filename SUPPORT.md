# Getting help

- **Bug reports and feature requests:** open an issue in the relevant repository and use the
  template. Include Minecraft version, loader version and logs where relevant.
- **Questions about usage:** check the repository's `README` first, then search existing
  issues. If your question is not answered, open an issue with the question label or use
  Discussions where they are enabled.
- **Security problems:** do not use public issues. See [SECURITY](SECURITY.md).

These projects are maintained by volunteers, so responses may take a while and support is
not guaranteed. Archived and frozen packs are not actively supported.
